# TLS Configuration Task

## Objective
There is an existing deployment in the `nginx-static` namespace that exposes an NGINX server over TLS. The goal is to:

1. Restrict the NGINX TLS configuration to only support TLSv1.3.
2. Map the service IP to `ckaquestion.k8s.local` in `/etc/hosts`.
3. Verify that TLSv1.2 fails and TLSv1.3 works.

## Required checks

- `curl -vk --tls-max 1.2 https://ckaquestion.k8s.local` → should fail
- `curl -vk --tlsv1.3 https://ckaquestion.k8s.local` → should work

## Initial setup

```bash
kubectl create namespace nginx-static

openssl req -x509 -nodes -days 365 -newkey rsa:2048 \
  -keyout /tmp/tls.key \
  -out /tmp/tls.crt \
  -subj "/CN=ckaquestion.k8s.local"

kubectl create secret tls nginx-tls \
  --cert=/tmp/tls.crt \
  --key=/tmp/tls.key \
  -n nginx-static
```

```bash
kubectl create configmap nginx-config \
  --from-literal=nginx.conf='events {}
http {
  server {
    listen 443 ssl;
    ssl_certificate /etc/nginx/tls/tls.crt;
    ssl_certificate_key /etc/nginx/tls/tls.key;
    ssl_protocols TLSv1.2 TLSv1.3;
    location / {
      return 200 "TLS configuration OK";
    }
  }
}' \
  -n nginx-static
```

```bash
kubectl apply -f - <<EOF
apiVersion: apps/v1
kind: Deployment
metadata:
  name: nginx-static
  namespace: nginx-static
spec:
  replicas: 1
  selector:
    matchLabels:
      app: nginx-static
  template:
    metadata:
      labels:
        app: nginx-static
    spec:
      containers:
      - name: nginx
        image: nginx:alpine
        ports:
        - containerPort: 443
        volumeMounts:
        - name: nginx-config
          mountPath: /etc/nginx/nginx.conf
          subPath: nginx.conf
        - name: tls-secret
          mountPath: /etc/nginx/tls
      volumes:
      - name: nginx-config
        configMap:
          name: nginx-config
      - name: tls-secret
        secret:
          secretName: nginx-tls
EOF
```

```bash
kubectl expose deployment nginx-static \
  --name=nginx-service \
  --port=443 \
  --target-port=443 \
  -n nginx-static
```

## Solution

### 1. Get the service IP
```bash
kubectl get svc nginx-service -n nginx-static
```

> Note the ClusterIP shown by the service. Use it in the next step.

### 2. Add the host entry
```bash
echo "<SERVICE_IP> ckaquestion.k8s.local" | sudo tee -a /etc/hosts
```

Example:
```bash
echo "10.106.27.127 ckaquestion.k8s.local" | sudo tee -a /etc/hosts
```

Verify the entry:
```bash
cat /etc/hosts | grep ckaquestion
```

### 3. Update the ConfigMap to TLSv1.3 only
```bash
kubectl edit configmap nginx-config -n nginx-static
```

Change the line:
```nginx
ssl_protocols TLSv1.2 TLSv1.3;
```

to:
```nginx
ssl_protocols TLSv1.3;
```

Then restart the deployment so the new config is loaded:
```bash
kubectl rollout restart deployment nginx-static -n nginx-static
```

### 4. Verify the behavior
```bash
curl -vk --tls-max 1.2 https://ckaquestion.k8s.local
curl -vk --tlsv1.3 https://ckaquestion.k8s.local
```

Expected result:
- The TLSv1.2 request should fail.
- The TLSv1.3 request should succeed.
