Task — StorageClass:

Create a new StorageClass named local-storage with the provisioner rancher.io/local-path

Set the VolumeBindingMode to WaitForFirstConsumer

Do NOT make the SC default initially

Patch the StorageClass to make it the default StorageClass

Ensure local-storage is the ONLY default class (remove default from any other existing SC)

Do not modify any existing Deployments or PersistentVolumeClaims

Solution 

# ── STEP 1: Check existing SCs ──
kubectl get sc

# ── STEP 2: Create local-storage SC (NO default annotation) ──
cat <<EOF | kubectl apply -f -
apiVersion: storage.k8s.io/v1
kind: StorageClass
metadata:
  name: local-storage
provisioner: rancher.io/local-path
volumeBindingMode: WaitForFirstConsumer
reclaimPolicy: Delete
EOF

# ── STEP 3: Remove default from existing SC ──
kubectl patch storageclass <existing-default-sc-name> \
  -p '{"metadata":{"annotations":{"storageclass.kubernetes.io/is-default-class":"false"}}}'

# ── STEP 4: Patch local-storage to be default ──
kubectl patch storageclass local-storage \
  -p '{"metadata":{"annotations":{"storageclass.kubernetes.io/is-default-class":"true"}}}'

# ── STEP 5: Verify only local-storage is default ──
kubectl get sc
kubectl describe sc local-storage | grep -i default
